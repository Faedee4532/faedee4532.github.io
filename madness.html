Madness — Linux Writeup

Executive Summary. An Easy THM CTF room (Mr. Robot themed). The entry is steganography and file forensics: a JPG that reports as plain data is really a PNG by its magic bytes, so its header is corrected to reveal a hidden directory. A numeric "secret" is brute-forced, and steghide pulls a username and password out of two images. Root comes from a SUID screen-4.5.0 binary and its classic sudo/pty exploit.

Phase 01 — Reconnaissance

nmap opens ports 22 (SSH) and 80 (Apache). The site shows the default Apache page; the HTML references an image that doesn't render. Download it and run file — despite the .jpg extension, its header says PNG. The file's magic bytes were simply mislabeled.

Phase 02 — Steganography

Correct the header (rebuild the JPEG signature with an online hex editor such as HexEd.it) and the image loads, revealing a hidden directory path. Visit it; it expects a ?secret= value and a source hint says the answer is between 0–99. Brute-force the parameter with Burp Intruder and the correct value is 73, which returns a code/password hint.

Use steghide info on the image to confirm a hidden file, extract hidden.txt with the same passphrase, and read the username. The same passphrase also pulls a password.txt from the banner image. The username was ROT13-encoded — decode it to get the real login.

Phase 03 — User Access

Log in via SSH (22) with the ROT13-decoded username and the steganographic password to read user.txt.

Phase 04 — Privilege Escalation

Enumerate SUID binaries with find / -type f -perm -04000 -ls. The standout is /bin/screen-4.5.0 (and a .old copy). Its version maps to a known SUID-screen privilege-escalation exploit (searchsploit), which reuses a root-owned shell session. Run the exploit's helper .sh to attach as root and read root.txt.

  • find / -type f -perm -04000 -ls to surface SUID binaries.
  • screen-4.5.0 — a SUID copy of the GNU screen binary.
  • Classic session-reuse exploit → root.

Findings & CVEs

  • Magic-byte forensics — a PNG mislabeled as JPG; header repair reveals a hidden path.
  • steghide — username and password extracted from two images using a brute-forced passphrase.
  • SUID screen 4.5.0 — session-reuse privesc.
