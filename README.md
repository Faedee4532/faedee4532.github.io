## How was it built?

The index.html on that page wasn't hand-coded. It was generated by a custom AI harness especially fitted for lower end models, built in Python on top of Ollama, that gives the model a detailed process for thinking, calling tools, and executing changes: one AI, one job.

The mastermind behind it: Qwen3.5:9b, customized into a variant called Ornith:9b, a fine tuned variant.

Running at a 98k context window, AND on hardware that has no business running a model like this efficiently, the AI produced this entire one-file solution in under 15 minutes and on minimal hardware:

- 4GB VRAM (GTX 1650)
- 10GB usable offloading RAM (out of 16GB total, overhead excluded)
