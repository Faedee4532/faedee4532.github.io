04 — What I've Built

ornith_cli

A custom Ollama-based agentic coding harness running on a locally hosted model (ornith:9b, Qwen3.5-9B hybrid), with a two-role orchestrator (ornith_cli_overseer.py) that splits large development goals into sequenced sub-prompts handled by separate Overseer and Agent roles. A tkinter GUI variant is designed and pending merge. Stack: Python, Ollama, Qwen3.5-9B hybrid, tkinter.

Local inference hardware evaluation

Benchmarked a larger 27B-class model (Qwen3.6-27B) at IQ3 quantization across two consumer GPUs (GTX 1650 Ti laptop, GTX 1650 desktop), identified RAM bandwidth as the hard bottleneck (~1.1 tok/s), and made the call to stay on the smaller daily-driver model rather than chase a size the hardware couldn't serve — then correctly scoped the next upgrade around VRAM (8GB+), not RAM. Stack: llama.cpp, quantization, GPU benchmarking.

ESP32 environmental monitor

Temperature and humidity monitor built on an ESP32-WROOM, reading from an AM2302/DHT22 sensor and displaying live data on an I2C SSD1306 OLED (address 0x3C). Built end-to-end as a gift for a mentor, with a custom enclosure planned. Stack: ESP32, I2C, DHT22, SSD1306.

06 — Final-Year Project (in progress)

Linux process monitor & threat scorer

Combines SHA-256 hash checks against MalwareBazaar, VirusTotal API lookups, and eBPF-based kernel behavioral monitoring via BCC/libbpf, feeding into a weighted threat-scoring engine with optional Isolation Forest anomaly detection. Process data pulled by polling /proc with psutil, ELF features extracted with lief, presented through a CustomTkinter dashboard, packaged with PyInstaller. Deliberately scoped to Linux only, and deliberately avoids LLM-based runtime inference — at detection time, latency and resource cost matter more than marginal accuracy gain.
