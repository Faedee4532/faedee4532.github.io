Valley — Linux Writeup

Executive Summary. An Easy THM box with three doors: SSH (22), HTTP (80), and FTP on a non-standard port (37370). The path is a layered credential hunt: a JS-embedded dev login, reused over FTP, unlocks a .pcapng full of an HTTP POST that leaks a user's password. A UPX-packed authenticator binary on the host is unpacked and string-mined for a second MD5. Root comes from hijacking Python's base64 module, which the root cron job imports every minute.

Phase 01 — Reconnaissance

rustscan/nmap -p- reveals ports 22 (SSH), 80 (HTTP), and 37370 (FTP). The site is a thin static gallery that loads images from a /static/ path. A two-digit fuzz (ffuf over /static/FUZZ) resolves /static/00 to a dev login page for "Valley Photo Co."

The page source leaks hardcoded developer credentials in dev.js. The same creds work for the FTP service on 37370, where a handful of .pcapng files are downloaded with mget.

Phase 02 — Initial Access

Open the captures in Wireshark and filter on http.request.method == POST. One of the five POSTs carries plaintext form credentials in the TCP stream. Those credentials log in via SSH as valleyDev and user.txt is read.

Phase 03 — User Access

In /home there is a valleyAuthenticator binary that prompts for a username and password. Run strings — it ends with UPX markers, so the file is packed. Unpack with upx -d, then re-run strings: two MD5 hashes are embedded. Crack them offline (John/rockyou) to recover a second user's password, then su valley.

Phase 04 — Privilege Escalation

The root cron job (/etc/crontab) runs /photos/schema/photosEncrypt.py every minute; it imports the base64 module to encode images. The script itself is root-owned and unwritable, but its imported base64.py (in /usr/lib/python3.8) is writable by the valleyAdmin group that valley belongs to.

Append a small payload to base64.py that the root job inherits:

  • import os; os.system("chmod u+s /bin/bash")
  • Wait for the next cron run, then ls -la /bin/bash to confirm the SUID bit.
  • Spawn the root shell with /bin/bash -p (the -p preserves the effective UID so privileges aren't dropped).

Findings & CVEs

  • pcapng credential extraction — HTTP POST plaintext in a captured stream.
  • UPX unpacking — upx -d reveals embedded MD5 hashes from a packed binary.
  • Python library hijack — writable base64.py imported by the root cron job → SUID bash.
