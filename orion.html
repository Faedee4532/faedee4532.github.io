Orion — Easy/Linux Writeup

Executive Summary. An Easy Linux box running a CraftCMS-backed site for a fictional telecom ("Orion Telecom"). The foothold is a known CVE in the CMS's image-transform endpoint (CVE-2025-32432), reached through a CSRF validation bypass; a misconfigured .env exposes the database, and a cracked, reused password gives SSH. Root comes from a legacy telnetd (CVE-2026-24061) authentication bypass on the loopback interface.

This machine was documented to client-deliverable report standard — findings, CVSS ratings, and a clean methodology — rather than as an informal note.

Phase 01 — Reconnaissance

nmap -sCV -oN on the target returns two open services: port 22 (SSH) and port 80 (nginx 1.18.0), which redirects to orion.htb. Adding the host to /etc/hosts and fingerprinting the stack with Wappalyzer reveals the site is built on Craft CMS + Yii. A directory/endpoints fuzz (ffuf) surfaces /admin (redirects to /admin/login) and /assets. The login portal footprints Craft CMS 5.6.16.

Phase 02 — Initial Access

Craft CMS 5.6.16 is vulnerable to CVE-2025-32432 — an authenticated RCE in the assets/generate-transform endpoint, which handles image transforms. A CSRF validation bypass lets an attacker stage a malicious PHP payload inside a temporary session file during the auth redirect; when the request is issued to the endpoint with a manipulated handle object, the framework deserializes the configuration without proper validation and executes arbitrary code.

  • Publish the payload, then trigger the transform with a discovered asset ID (read from the response headers).
  • Fire the payload with curl or Burp to catch a www-data shell.
  • Upgrade to a PTY with python3 -c 'import pty;pty.spawn("/bin/bash")'.

Phase 03 — User Access

Enumerate the Craft directory and read the environment file at /var/www/html/craft/.env. It stores MySQL credentials in plaintext: CRAFT_DB_USER=root, CRAFT_DB_PASSWORD=SuperSecureCraft123Pass!. Connect to the local MariaDB/MySQL (mysql -u root -p) and query the users table — the adam account carries a bcrypt hash ($2y$13$...). Crack it with Hashcat (-m 3200, rockyou), then log in via SSH as adam (credential reuse) to read user.txt.

Phase 04 — Privilege Escalation

Enumerate local listeners with ss -lntp and find port 23 open (a telnet server). Check the daemon version and locate CVE-2026-24061 in the GNU inetutils telnetd. The exploit abuses argument parsing: by setting USER='-f root' and running telnet -a 127.0.0.1 23, the client forwards authentication for root and the authentication bypass spawns a root shell on loopback.

  • env USER='-f root' telnet -a 127.0.0.1 23
  • The -a flag enables automatic login, which reads the injected USER value as the forward target.
